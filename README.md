# Manifesto das Pontes / Bridges Manifesto

Manifesto público de intenção e progresso em continuidade de agentes de IA. Estado descrito: 31 de outubro de 2026. O texto não anuncia que a ferramenta esteja pronta; distingue resultados observados, seus limites e o compromisso de distribuição futura pública e gratuita.

Public statement of intention and progress on AI-agent continuity. State described: October 31, 2026. The text distinguishes demonstrated results and limits from the commitment to future public, free availability of the tool.

## Idiomas / Languages

- `pt/`: Português
- `en/`: English
- `es/`: Español
- `fr/`: Français
- `de/`: Deutsch
- `ru/`: Русский
- `ar/`: العربية
- `hi/`: हिन्दी
- `zh/`: 简体中文
- `ja/`: 日本語

Em cada pasta: `manifesto.md`, `manifesto.txt`, `manifesto.json`, `manifesto.jsonl`, `manifesto.pdf` e `manifesto.tex`. O JSON preserva o Markdown integral; cada linha do JSONL contém um objeto, com uma seção por objeto. O índice `SHA256SUMS` registra os hashes dos 60 arquivos e deste README; o hash detecta alterações quando comparado a uma referência confiável, não prova autoria.

Each language folder contains Markdown, plain text, JSON, JSON Lines, PDF and XeLaTeX source. JSON retains the complete Markdown; JSONL has one object per section. `SHA256SUMS` lists the 60 files and this README. Hashes do not independently establish authorship.

Para compilar `.tex`, são necessários XeLaTeX, os pacotes `fontspec` e `geometry` (e `bidi` para árabe), além das fontes Noto correspondentes. Os fontes TeX foram gerados, mas não compilados neste ambiente; os PDFs foram produzidos separadamente com Pango/Cairo.

To compile `.tex`, XeLaTeX, `fontspec`, `geometry` (`bidi` for Arabic) and the relevant Noto fonts are required. TeX sources were generated but not compiled in this environment; PDFs were generated separately with Pango/Cairo.

As traduções são disponibilizadas para leitura e revisão; questões de tradução podem ser corrigidas em versões futuras. Licenciamento e dependências da futura ferramenta serão definidos antes do lançamento.
